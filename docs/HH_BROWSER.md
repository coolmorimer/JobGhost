# HH без API

Требуется установленный Microsoft Edge. Python-зависимость Playwright включена в backend/pyproject.toml.

1. Запустите backend без `--reload`: из backend выполните `.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765`.
2. Запустите frontend (`npm run dev` из frontend) и откройте http://127.0.0.1:5173.
3. В разделе Vacancies нажмите «Открыть вход в HH». В отдельном Edge войдите самостоятельно, затем нажмите «Я вошёл — проверить».
4. «Найти на HH» читает одну страницу реальных карточек и сохраняет их без повторного добавления.
5. «Подробнее» → «Открыть в браузере HH» открывает оригинал вакансии.

Отдельный профиль браузера находится в `.jobghost/browser/hh`, исключён из git. Не передавайте эту папку другим людям: она содержит авторизованную сессию. Обычный профиль Edge не используется. Закрытие сервера закрывает управляемый браузер; сохранённый профиль остаётся.

Пароли, коды и капчи вводятся пользователем. Автоматизация не обходит защиту HH. Вход считается подтверждённым только при обнаружении ссылки «Мои резюме»; в другой версии интерфейса статус может остаться неподтверждённым.

Ограничения текущего этапа: поиск, фоновое расписание и открытие карточек. Зарплата и полное описание не нормализуются, автоматическая отправка откликов, чтение резюме и переписки ещё не реализованы. Это не полный автопилот. ChatGPT и голос этот модуль не подключает. Поиск не вызывает AI-модели.

## Фоновый запуск

Из корня проекта: `powershell -NoProfile -File scripts/start-background.ps1`. Интерфейс собранного приложения доступен на http://127.0.0.1:8765; Vite и открытый Codex не нужны. Сервер запускается отдельным скрытым процессом. Компьютер должен оставаться включённым, без сна. Автозапуск Windows пока не устанавливается.

В разделе Vacancies задайте запрос и интервал (5–1440 минут), нажмите «Запустить в фоне». Edge перезапускается без видимого окна с тем же отдельным профилем HH. Настройки, следующие запуски и последние 30 результатов сохраняются в БД. После перезапуска сервера включённый поиск восстанавливается, сохраняя срок следующего прогона. Капча, таймаут или ошибка переводят пилот в «Нужно ваше действие» без бесконечных повторов. «Пауза» останавливает текущую задачу. Открытие входа или вакансии вручную ставит пилот на паузу; после ручного действия его нужно запустить снова.

Реальный headless-прогон 10 сентября: 20 карточек, 17 новых. Кнопка паузы проверена в браузере. 20 backend-тестов проходят, включая восстановление состояния и остановку при ошибке. Не проверены личный кабинет, отправка откликов и AI-связка.

Проверено 10 сентября 2026: реальный запуск Edge через backend и поиск Python вернули 19 карточек HH; сохранение и отображение проверены в браузере. Проверка входа в личный аккаунт требует пользователя. Backend: 17 тестов; frontend: сборка и ESLint проходят.
