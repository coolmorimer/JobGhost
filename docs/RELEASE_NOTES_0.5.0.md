# JobGhost 0.5.0

- Добавлены три канала ответов: OpenRouter, OpenAI API и существующий ChatGPT в Chrome.
- OpenRouter автоматически получает актуальный каталог, исключает платные и служебные модели и использует до четырёх самых быстрых бесплатных моделей с резервом.
- OpenAI использует быстрые модели и Responses API с отключённым хранением ответа (`store: false`).
- Ответы API отображаются потоково сразу по мере генерации; скрытый чат также растёт вместе с текстом.
- API-ключи сохраняются только в Windows Credential Manager и никогда не возвращаются в интерфейс.
- Роль по резюме работает для всех трёх каналов.
- Задержка голосового тракта уменьшена: фрагменты 2,4 секунды, быстрый greedy decode и укороченный VAD.

После обновления откройте «Настройки → ИИ», выберите канал и сохраните ключ. Для старого режима Chrome ничего перенастраивать не требуется.
