# JobGhost 0.5.2

Дата: 11 сентября 2026.

Статус: предварительный выпуск. Реальный HH canary не подтвердил резюме и письмо; автоматические повторы заблокированы, требуется ручная проверка результата на HH. Не использовать массовые отклики до закрытия этого пункта аудита.

## Главное

- Независимые источники «Микрофон» и «Собеседник» с отдельным распознаванием и подписями.
- Третий канал — только ручное изображение: область или весь экран. Автоответы снимок не получают.
- Локальный Faster Whisper `large-v3-turbo` использует RTX/CUDA float16 и откатывается на CPU int8.
- OpenAI Live передаёт RU/EN transcription delta через локальный защищённый WebSocket, не отдавая API-ключ интерфейсу.
- Голосовой draft виден прямо в поле вопроса; длинная реплика собирается до паузы, `Ctrl+Enter` отправляет её вручную.
- OpenAI/OpenRouter отвечают потоково. OpenRouter `auto` передаёт не больше трёх бесплатных моделей.
- Markdown отображается нормально; compact-окно растёт по длине ответа и допускает ручной resize/drag.
- Полный снимок можно сделать независимо от включённого системного звука.

## Проверено

- Backend: Ruff, 68 pytest.
- Frontend: 25 Vitest, ESLint, production build, npm audit.
- Browser extension: 41 Node test.
- Desktop: 11 Node test, Electron native/screen/audio pipeline.
- Реальная RTX 3060: точный RU-вопрос из 5,57-секундного SAPI fixture распознан за 0,86–1,03 с после окончания фразы.
- Реальные API: OpenAI Live, четыре быстрые OpenAI-модели, OpenRouter auto и роль по резюме.
- Реальный Chromium UI: русские настройки и основной сценарий без console errors.
