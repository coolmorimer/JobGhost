# Голосовой тракт: состояние на 11 сентября 2026

## Каналы

Микрофон и системный звук идут независимыми дорожками. В истории видно, кто
произнёс реплику: «Микрофон» или «Собеседник». Одновременная речь не склеивается
в один вопрос. Изображение является третьим, полностью ручным каналом: область
или весь экран прикрепляется только к следующему ручному запросу.

## Локальная речь

Каждый источник создаёт отдельные WebM-фрагменты раз в 2,5 секунды.
`VoiceUtteranceAssembler` соединяет их до паузы, переносит язык RU/EN и удаляет
повтор на границе. Вопросительный знак промежуточного фрагмента не завершает
длинную реплику.

На Windows сначала выполняется реальный пробный inference Faster Whisper
`large-v3-turbo` через NVIDIA CUDA float16. CUDA DLL загружаются из локальных
пакетов приложения, без изменения системного PATH. Если проба не проходит,
упакованная модель переключается на CPU int8; это заметно медленнее. В
dev-режиме без локально упакованной модели CPU загружает более лёгкую `small`.
Статус показывает фактическое устройство.

## OpenAI Live

Renderer преобразует каждый источник в mono PCM16 24 кГц примерно каждые
85 мс. Backend проксирует аудио в `gpt-live-transcribe`; API-ключ остаётся в
Windows Credential Manager и никогда не передаётся renderer.

Модель требует явного commit, поэтому JobGhost выполняет VAD отдельно для
каждой дорожки: хранит короткий префикс, начинает передачу при появлении голоса
и завершает реплику после 1,1 секунды тишины. Transcript delta сразу обновляет
поле вопроса. Финальная реплика может уйти автоматически только после паузы;
`Ctrl+Enter` отправляет текущий видимый текст вручную.

## Защита от перегрузки

Локальные фрагменты проходят через одну ограниченную последовательную очередь,
потому что один экземпляр модели защищён lock. У каждого источника свой язык и
сборщик реплики. При остановке очередь очищается, старые результаты игнорируются,
WebSocket, MediaRecorder и аудиотреки закрываются.

## Подтверждённые проверки

- RTX 3060: `large-v3-turbo`, CUDA float16, пробный inference при загрузке.
- Тестовая русская фраза распознана точно; полный Electron/WebM прогон после
  прогрева занял 0,86–1,03 с после окончания 5,57-секундной фразы.
- OpenAI Live принял сессию и вернул 10 промежуточных delta плюс точный финальный текст.
- Synthetic SAPI WAV → WebAudio → MediaRecorder/WebM → backend проверяется
  `desktop/test-audio-pipeline.cjs`.

Физические микрофон и loopback требуют ручного выбора источника и согласия
участников; автоматический тест не захватывает пользовательские окна или речь.
