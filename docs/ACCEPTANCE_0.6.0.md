# Приёмка контекста и подготовки — 2026-09-11

## Реализовано

- Локальные материалы (резюме/проекты/опыт/вакансия), выбор источников, удаление и редактирование через удаление/повторное добавление.
- Qdrant RAM + реальная multilingual FastEmbed модель, фрагменты и источники в ответе.
- Общий Context Builder для API и browser-канала; API-сессии с отдельной ролью и bounded history.
- История только по явному opt-in, просмотр и удаление; звук и изображения не сохраняются модулем памяти.
- AI Coach с оценкой и рекомендациями; формат и диапазоны валидируются.
- Чтение ссылки HH без отклика, план 30 вопросов/ответов и чеклист, экспорт Markdown.
- Для структурированных задач OpenRouter отбирает бесплатные модели с поддержкой схемы; нет скрытого перехода на платную модель. Один этап ограничен 120 секундами.

## Выполненные проверки

- Backend: 88 тестов; Ruff без ошибок. Имеются 267 deprecation warnings прежних datetime/Starlette APIs.
- Frontend: 30 тестов, ESLint и production build.
- Extension: 41 тест; Desktop: 14 unit-тестов. Всего 173 автоматических теста.
- Реальный RU/EN-поиск: обе формулировки выбрали PostgreSQL-фрагмент вместо React; cosine score 0.643 / 0.683.
- Реальные OpenAI API: Coach прошёл (примерно 6 секунд), последовательный вопрос сохранил тему PostgreSQL; план 30/30 за 48.9 секунды. Повторный прогон со строгой схемой: Coach 5.68 секунды, план 30/30 и 48 пунктов чеклиста за 25.73 секунды на синтетической вакансии.
- Реальные OpenRouter: Coach и последовательные вопросы прошли; полный план не прошёл из-за нестабильного формата/сетевого таймаута. После обнаружения проблемы добавлены строгая схема, фильтр совместимости моделей, общий timeout и непустое сообщение сетевой ошибки. Полный успешный план OpenRouter не заявляется.
- Playwright: добавление материала через реальные поля, нормальная и узкая ширина 640px, снимки просмотрены. Ошибки соединения в консоли соответствовали намеренным перезапускам тестового backend, не JS-исключениям интерфейса.
- Финальный упакованный backend (`build-bba77a6c70084b4eb7f70ed30e80486b`) запущен отдельно на 127.0.0.1:8766 и успешно загрузил multilingual FastEmbed: `/api/preparation/load` вернул `ready: true`.

Все внешние запросы содержали синтетический текст. Рабочая БД, резюме и очередь HH пользователя не использовались. Установленное приложение не обновлялось автоматически.
