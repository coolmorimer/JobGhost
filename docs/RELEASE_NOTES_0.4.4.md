# JobGhost 0.4.4

Первая публичная Windows-сборка локального помощника для собеседований и HH.

## Главное

- обычный ChatGPT в Google Chrome без OpenAI API и кода подключения;
- служебное окно Chrome скрывается Windows API и не показывается в Alt+Tab;
- роль кандида по выбранному резюме загружается при старте сессии;
- локальный Faster Whisper `small` для русской и английской речи;
- автоопределение вопросов и ручная отправка по `Ctrl+Enter`;
- минимальный адаптивный overlay, прозрачность, клики насквозь и включаемая защита от захвата;
- выбор области снимка и HH-автопилот с остановкой на CAPTCHA и неопределённом результате;
- русский Inno Setup с автономным backend и встроенной моделью речи.

## Первый запуск

После установки один раз загрузите папку `resources/browser-extension` через `chrome://extensions` и войдите в ChatGPT. После этого подключение и скрытие браузера автоматические.
