# JobGhost: фоновый мост ChatGPT

Расширение связывает локальное приложение JobGhost с обычным ChatGPT в Google
Chrome. Оно не использует API-ключ, не читает cookies или пароли и не
обходит вход, CAPTCHA или ограничения аккаунта.

## Установка один раз

1. Установите JobGhost и запустите его.
2. Откройте `chrome://extensions`.
3. Включите режим разработчика и нажмите «Загрузить распакованное».
4. Выберите папку `browser-extension` из каталога установки JobGhost.
5. Если браузер попросит, войдите в ChatGPT вручную.

После этого коды не нужны. Расширение каждые 30 секунд проверяет локальный
JobGhost, находит либо открывает служебную вкладку ChatGPT, получает
краткоживущий допуск и переносит вкладку в отдельное свёрнутое окно. Страница
настроек расширения может быть закрыта.

Первую установку расширения нельзя скрыто выполнить за пользователя: Chrome
намеренно требует явного действия. После установки приложение может
само запускать браузер, а расширение — чат и подключение.

## Обычная работа

- Запустите JobGhost и пишите в его минимальном чате.
- Браузер и служебная вкладка ChatGPT должны работать, но могут быть свёрнуты.
- Если вход слетел, расширение покажет ChatGPT. Войдите вручную; затем нажмите
  значок JobGhost или дождитесь следующей автоматической проверки.
- Не вводите сообщения одновременно в служебном чате.
- При неопределённой отправке автоматического повтора нет: сначала проверьте
  черновик или последнее сообщение в ChatGPT.

Код в настройках сохранён только как запасная диагностика старого способа.

## Экран и данные

Вопрос и только выбранный пользователем снимок/область передаются в ChatGPT и
могут сохраниться в истории этого чата. Локальное распознавание речи не
отправляет аудио в ChatGPT: передаётся полученный текст. Системный буфер обмена
не читается и не изменяется.

Расширение имеет доступ только к `chatgpt.com` и локальному
`127.0.0.1:8765`. Разрешения `tabs` и `scripting` нужны для поиска
служебной вкладки, заполнения поля, однократной отправки и получения нового
ответа. `alarms` будит фоновую проверку. Доступа к cookies, history, debugger,
паролям и остальным сайтам нет.

Автоматический допуск выдаётся только запросам с origin установленного
Chromium-расширения, живёт 120 секунд, привязан к конкретному ID расширения и
принимается WebSocket-соединением один раз.

## Проверки разработчика

```powershell
node --test browser-extension/tests/*.test.mjs
cd backend
.\.venv\Scripts\python.exe -m pytest tests/test_extension_socket.py tests/test_chat_bridge.py -q
```

Fixture-тесты проверяют отсутствие повторов, сохранение чужого черновика,
ожидание завершённого ответа, вложение JPEG, автоматический выбор/создание
вкладки и фоновое окно. Совместимость с текущим живым интерфейсом ChatGPT
подтверждается отдельным реальным прогоном после каждого значимого изменения
сайта.
